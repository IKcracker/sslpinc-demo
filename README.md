# SSLP Inc. React website redesign

Independent website redesign concept for Scheflen Speech-Language Pathology, Inc. Not affiliated with or operated by SSLP.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Stack: React, Vite, React Router and responsive CSS. The form composes an email; it is not a live intake service. Verify all company information, services and contacts before sharing publicly. Deploy to Vercel using the Vite preset; output directory: `dist`.
